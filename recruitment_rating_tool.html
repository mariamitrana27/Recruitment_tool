How the score works

Each of the 8 dimensions gets a rating worth points: Low = 0, Mid = 1, High = 3, Very High = 5. The Score is the sum across all 8 (max 40), then matched to a Growth path / seniority level — same logic as the source spreadsheet's formulas.

How this connects to a shared Excel file (setup, once, by an admin)

This page cannot silently read or write a file on OneDrive/SharePoint by itself — browsers block that for security reasons. The supported way to get a live, auto-updating Excel history behind a Teams tab is two small Power Automate flows (no Azure app registration needed, just the standard "Excel Online (Business)" connector against the Excel file in your team's SharePoint/OneDrive):

  1. "Add candidate" flow: trigger = "When an HTTP request is received" → action = "Add a row into a table" on the shared history Excel file. Copy the flow's HTTP POST URL into ADD_ROW_FLOW_URL below in this file.
  2. "Get history" flow: trigger = "When an HTTP request is received" (GET) → action = "List rows present in a table" → a "Response" action returning that data as JSON, with header Access-Control-Allow-Origin: * added manually so the browser is allowed to read it. Copy that URL into GET_ROWS_FLOW_URL.

Once both URLs are filled in near the top of the <script> section and the file is (re)published as the Teams tab, every new candidate is appended to the shared Excel file automatically, and everyone opening the tab loads the same history from that file.

Security note: a Power Automate HTTP-trigger URL acts like a password — anyone with it can call the flow. Treat it as a secret: don't post it in a public channel, and keep the Teams tab restricted to your team. This tool never sends it anywhere except the two flow URLs you configure.

Until these are configured, the tool keeps working exactly as before — all data lives only in this browser tab, and you can still use Export data (JSON) / Export CSV to save or share your work manually.

Internal tool for GDC recruitment. Ratings reflect interviewer judgement and should be discussed with the hiring panel before any decision — this tool does not make hiring decisions on its own. New candidates are appended to the shared Excel history as an audit trail once Excel sync is configured; editing or deleting a candidate here only changes your local view, not past Excel rows.
